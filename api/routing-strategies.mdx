This is the HTTP route reference for **Lasso RPC Core v0.4.4**. The
[routing strategy contract](/concepts/routing-strategies) defines ranking, health
tiers and execution limits. [Cloud RPC behavior](/cloud/rpc-behavior) separately
describes the managed service.

## Routes

| POST route | Behavior |
| --- | --- |
| `/rpc/:chain` | Application default; shipped as `load_balanced` |
| `/rpc/load-balanced/:chain` | Randomized order with distinct-instance first pass for replay-safe calls |
| `/rpc/fastest/:chain` | Recent reliability-qualified latency order |
| `/rpc/latency-weighted/:chain` | Relative-latency weighted permutation |
| `/rpc/provider/:provider_id/:chain` | Explicit configured provider |

For an explicit file profile, use `/rpc/profile/:profile` before the strategy
and chain segments:

```bash
curl 'http://localhost:4000/rpc/profile/public/fastest/ethereum?include_meta=body' \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":1}'
```

The chain must be configured in that profile. Core has no dedicated `priority`
URL route; select `:priority` as the application default and use the base route.
Profile YAML does not support per-method strategy overrides.

## Health and failover

The order is closed/unlimited, half-open/unlimited, closed/rate-limited, then
half-open/rate-limited. Open circuits are excluded. Live admission remains
required after ranking.

Replay-safe reads can fail over within their bounded three-dispatch envelope.
Transaction, signing, filter and unknown-method execution have separate rules;
see [supported methods](/api/supported-methods). URL strategies on WebSockets
apply to forwarded calls; subscription pool selection is independent of that
strategy.

## Inspect routing

Use `include_meta=headers` or `include_meta=body`. The
[metadata reference](/observability/request-metadata) contains the released fields
and generated success/failover examples. A candidate list alone does not prove
which provider handled a request.

Routes are defined in the released
[Core router](https://github.com/jaxernst/lasso-rpc/blob/v0.4.4/lib/lasso_web/router.ex).
