# Lasso documentation

Lasso puts one standard JSON-RPC endpoint in front of many EVM providers and
nodes. It routes each request by live latency and health, fails over before
your app sees an error, and shows which provider served every call. You change
a URL, not your code.

- **[Lasso Cloud](/cloud/overview)** is the hosted endpoint: managed provider
  pools, your own providers as Custom profiles, keys, one USD balance, live
  dashboards and an API agents can drive end to end. Start with the
  [Cloud quickstart](/cloud/quickstart).
- **[Lasso RPC Core](/introduction)** is the open-source routing engine you run
  on your own infrastructure. Start with the [Core quickstart](/quickstart).

[Versions and evidence](/releases-and-availability) compares the two, and
[support and lifecycle](/support-security-lifecycle) explains how to get help.
