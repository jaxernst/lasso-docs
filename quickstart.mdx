# Quickstart

Run Lasso RPC Core locally and route your first requests. The bundled `public`
profile uses free public providers, so you need no provider keys. You need
Docker Compose and OpenSSL.

## 1. Start the container

```bash
mkdir lasso && cd lasso
curl --fail --location https://github.com/jaxernst/lasso-rpc/releases/download/v0.6.0/compose.yml --output compose.yml
(umask 077; printf 'SECRET_KEY_BASE=%s\nRELEASE_COOKIE=%s\n' "$(openssl rand -hex 64)" "$(openssl rand -hex 32)" > .env)
docker compose up -d --wait
```

The dashboard is at [http://localhost:4000/dashboard](http://localhost:4000/dashboard).
[Installation](/installation) covers the container's storage, ports and
source builds.

## 2. Send a request

```bash
curl --fail-with-body -sS http://localhost:4000/rpc/ethereum \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":1}'
```

```json
{"jsonrpc":"2.0","id":1,"result":"0x18ba3fb"}
```

Add `?include_meta=headers` to the URL and `-i` to curl to see which provider
served it. [Request metadata](/observability/request-metadata) defines each
field.

## 3. Subscribe over WebSocket

```bash
npx --yes wscat -c ws://localhost:4000/ws/rpc/ethereum
```

At the `>` prompt, send:

```json
{"jsonrpc":"2.0","method":"eth_subscribe","params":["newHeads"],"id":1}
```

You get a subscription ID, then an `eth_subscription` notification per block.
The dashboard has a WebSocket tester too.

## 4. Choose a route

| Route | Use it for |
|---|---|
| `/rpc/fastest/ethereum` | Latency-critical reads |
| `/rpc/balanced-fast/ethereum` | Spreading load while favoring fast providers |
| `/rpc/load-balanced/ethereum` | Backends and indexers |
| `/rpc/profile/my-app/ethereum` | A profile you configured, named `my-app` |

WebSocket routes take the same segments under `/ws/rpc/`.
