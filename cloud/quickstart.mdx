# Quickstart

Create an endpoint, call it, and put it in your app. It takes one HTTP request
and no signup, so an agent can do every step. Prefer a browser? Sign in at
[lasso.sh](https://lasso.sh), create an endpoint, and skip to
[step 3](#3-put-it-in-your-app); it serves on public providers under your free
monthly allowance until you add balance or subscribe to Pro.

## 1. Create an endpoint

```bash
curl -sS https://lasso.sh/api/v1/keys \
  -H 'content-type: application/json' -d '{"name":"prod"}'
```

```json
{
  "key": "lasso_…",
  "rpc_url": "https://lasso.sh/rpc/k/lasso_…/profile/premium",
  "ws_url": "wss://lasso.sh/ws/rpc/k/lasso_…/profile/premium",
  "account_id": "…",
  "management_token": "lasso_mk_…",
  "serving_ready": true
}
```

You now have an account with a small starting balance and its first key. Save
`rpc_url` as `LASSO_RPC_URL`, and keep `management_token` private: it lets you
add keys, build Custom profiles and hand the account to a person later.

If the response is `202` with `serving_ready: false`, wait `Retry-After`
seconds, then send the RPC call below to the saved `rpc_url`. Retry RPC if
it is still pending, honoring `Retry-After`; the key already exists.

## 2. Call it

Append a chain to `rpc_url`, and optionally a strategy before it:

```bash
curl -fsS --retry 5 "$LASSO_RPC_URL/fastest/base?include_meta=body" \
  -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"eth_blockNumber","params":[]}'
```

```json
{
  "jsonrpc": "2.0", "id": 1, "result": "0x323b878",
  "lasso_meta": {
    "strategy": "fastest", "chain_id": 8453,
    "selected_provider": { "id": "premium_base_2", "protocol": "http" },
    "upstream_latency_ms": 9.7, "lasso_overhead_ms": 3.1, "retries": 0
  }
}
```

`lasso_meta` names the provider that served the call and where the time went.
Every response also carries `x-lasso-usd`, what the call cost, and
`x-lasso-balance-usd`, what's left.

For free Ethereum RPC, save the returned `key` as `LASSO_RPC_KEY` and derive
the public path from `rpc_url`. The premium path uses the starting balance;
public providers have no request charge.

```bash
LASSO_PUBLIC_RPC_URL="${LASSO_RPC_URL%%/rpc/*}/rpc/profile/public/ethereum"
curl -fsS "$LASSO_PUBLIC_RPC_URL?include_meta=body" \
  -H "authorization: Bearer $LASSO_RPC_KEY" \
  -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"eth_blockNumber","params":[]}'
```

## 3. Put it in your app

```bash
# .env
LASSO_RPC_URL=https://lasso.sh/rpc/k/lasso_…/profile/premium
LASSO_WS_URL=wss://lasso.sh/ws/rpc/k/lasso_…/profile/premium
```

```ts
import { createPublicClient, http } from "viem";
import { base } from "viem/chains";

const client = createPublicClient({
  chain: base,
  transport: http(`${process.env.LASSO_RPC_URL}/base`),
});
```

ethers, Foundry (`--rpc-url`), Hardhat and indexers take the same URL; use
`${LASSO_WS_URL}/base` for subscriptions. [Install Lasso](/cloud/install) has
an example for each.

## 4. Pick a strategy per call site

The strategy is a URL segment, so each call site can choose its own:

| Strategy | Use it for | Premium price |
|---|---|---|
| `balanced-fast` (the default) | User-facing reads | 1.5x |
| `fastest` | Trading and other latency-critical paths | 2x |
| `load-balanced` | Backends and indexers | 1x |
| `priority` | A preferred primary with backups, on a Custom profile | 1x |

To route over Lasso's public providers at no charge, replace `/profile/premium`
with `/profile/public`. [Routing](/cloud/routing) explains each strategy and
[keys and profiles](/cloud/keys-and-profiles) each pool.

## 5. Fund it

The starting balance covers a few thousand `eth_blockNumber` calls. To add more, credit the
account with USDC from the wallet your user approved:

```http
POST https://lasso.sh/api/v1/accounts/{account_id}/credit
Content-Type: application/json

{"usd":"5"}
```

Lasso answers `402` with a standard x402 or MPP challenge. Sign it with a stock
client and repeat the request. [Top up](/cloud/balance-and-fallback#top-up) has
a complete example, and people can add balance or subscribe to Pro in the
dashboard.

## Limits

- Creating endpoints without credentials is limited to 10 per hour per client
  IP.
- No Lasso credential can spend money; every payment needs a wallet signature.
